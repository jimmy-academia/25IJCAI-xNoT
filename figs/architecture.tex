\caption{Overview of the ANoT architecture. \textbf{Phase 1 (Planning)} transforms user requests into validated executable scripts, cached across items. \textbf{Phase 2 (Adaptation)} detects content heterogeneity and potential attacks before execution. \textbf{Phase 3 (Execution)} processes each evidence source independently via split-context LLM calls, then aggregates results using three-valued logic ($+1$: satisfied, $0$: unknown, $-1$: violated).}
