\section{Problem Formulation}

\subsection{Task Definition}

Given candidate items $\mathcal{I} = \{I_1, \ldots, I_n\}$ and a Boolean request $R$, select $I^* = \arg\max_{I \in \mathcal{I}} \sigma(I, R)$ where $\sigma: \mathcal{I} \times \mathcal{R} \to \{-1, 0, +1\}$ is the three-valued satisfaction function defined below.

Each item $I = (\mathbf{m}, \mathbf{h}, \mathbf{D})$ comprises structured metadata $\mathbf{m}$ (categorical and Boolean attributes), operating hours $\mathbf{h}$, and a document set $\mathbf{D} = \{d_1, \ldots, d_k\}$ of user reviews with associated metadata.

\subsection{Request Formalism}

Each request $R$ is a Boolean expression tree where leaf nodes specify conditions with an aspect name and evidence source, and internal nodes apply AND/OR operators.
Evidence sources indicate where to find supporting information:
\begin{itemize}[nosep]
    \item \texttt{item\_meta}: Direct attribute lookup in $\mathbf{m}$
    \item \texttt{item\_hours}: Time-window containment in $\mathbf{h}$
    \item \texttt{review\_text}: Semantic analysis of review content
    \item \texttt{review\_meta}: Filtering over reviewer signals
\end{itemize}

\subsection{Three-Valued Semantics}
\label{sec:problem}

Real-world evidence is often incomplete or ambiguous.
We adopt three-valued logic~\cite{fitting1985kripke} where each condition evaluates to $v \in \{+1, 0, -1\}$ (satisfied, unknown, violated).
Boolean operators extend naturally:
\begin{equation}
    a \land b = \min(a, b), \quad a \lor b = \max(a, b)
\end{equation}
This ensures violations dominate conjunctions while satisfactions dominate disjunctions, with unknown values propagating only when outcome-relevant.

\subsection{Evaluation}

Each request has exactly one ground-truth item with $\sigma(I^*, R) = +1$, enabling unambiguous evaluation.
We measure Hits@$k$:
\begin{equation}
    \text{Hits@}k = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathbf{1}[\text{rank}_r(I^*) \leq k]
\end{equation}
where $\text{rank}_r(I^*)$ is the ground-truth item's position in the method's ranking.
